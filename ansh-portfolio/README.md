# Ansh Shrivastav — Personal Portfolio

A responsive, single-file portfolio website for Ansh Shrivastav.

## Preview locally
Open `index.html` in a browser. The page is static and does not require npm or a build step.

## Sections
- Hero / introduction
- Selected projects: BEMATLAB, SSA Hotel & Residences, Ansh Demo, WEBYONEEC
- About
- Skills and toolkit
- Build process
- Contact links

## Customize
Edit `index.html` to update project descriptions, URLs, skills, social links, and contact email. The current portfolio uses the contact email `team.webyoneec@gmail.com`.

## Deploy
This folder can be deployed as a static site on Netlify, GitHub Pages, or Firebase Hosting. For Firebase Hosting, set the hosting public directory to `ansh-portfolio` if deploying from the repository root.

External font loading uses Google Fonts; the site remains readable with system fallbacks if fonts are unavailable.
