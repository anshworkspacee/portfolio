# ANSH — THE BUILDER

A cinematic, streaming-inspired portfolio based on the original React + TypeScript project, adapted for Ansh Shrivastav.

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Content
Portfolio content lives in `src/data/portfolio.ts`. Update the profile, projects, skills, journey, and contact information there.
